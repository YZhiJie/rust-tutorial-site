这套教程有什么不同 ​

浏览器里直接跑

每个核心示例都内置 Rust 编辑器。改一行代码、按一次运行，立刻看到编译信息与真实输出，不必先配环境。

以所有权为主线

不从语法清单出发，而是沿着借用检查器的思路讲：为什么需要所有权、生命周期如何推导、trait 如何组织抽象。

六阶段递进

入门、核心、抽象、进阶、工程、实战。每一阶段都给出明确的学习目标、练习与排错清单，避免“看懂但写不出”。

落到真实工程

最后三个项目分别覆盖 CLI、Web 服务与 WASM 前端，串联 Cargo 工作区、测试、错误处理、异步与性能优化。

六阶段学习路径 ​

01入门篇工具链、Cargo、变量与类型、控制流、函数与模块。建立可运行的 Rust 心智模型。02核心篇所有权、借用、生命周期、结构体、枚举、模式匹配、集合与迭代器。03抽象篇trait、泛型、trait 对象、错误处理与智能指针，写出可复用、可组合的代码。04进阶篇线程、消息传递、共享状态、async/await、宏、unsafe 与 FFI 的边界。05工程篇单元测试、文档测试、基准与性能剖析、Cargo 工作区与持续集成。06实战篇从零实现 CLI 工具、axum Web 服务与 WASM 前端，完成从知识到交付的闭环。

怎么用这套教程 ​

1

先读概念

每章开头列出学习目标。先理解问题与约束，再看代码，避免死记语法。

2

改代码再运行

把示例当成实验台：改变量、删一行、制造错误，观察编译器如何反馈。

3

完成练习

每章末尾有动手练习与折叠答案。先独立完成，再对照参考答案复盘。

示例通过官方 Rust Playground 执行，需要联网。首次编译通常需要 1–3 秒；若遇到服务限流，可点击示例右上角的「在 Playground 打开」直接跳转。
