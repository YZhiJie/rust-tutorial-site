实战：WASM 前端 ​

学习目标

  • 理解 WebAssembly（WASM）与 JavaScript 的分工边界
  • 用 wasm-bindgen 0.2 导出 Rust 函数与结构体
  • 用 wasm-pack 生成可被前端引用的产物
  • 用 Vite 加载 WASM 模块并完成构建部署

项目需求 ​

实现浏览器端文本统计器：输入文本，计算字符数、词数、去重词数、预计阅读时长与高频词 Top 5。

  • 统计逻辑用 Rust 编写，编译为 WebAssembly 在浏览器执行；
  • JavaScript 只读取输入、调用导出函数并渲染结果；
  • 不引入前端框架，使用 Vite 作为开发服务器与打包器（bundler）。

分词采用「按空白切分 + 去除首尾标点」的规则，适用于空格分隔的语言。中文没有空格，整句会被当成一个词，因此这里只作演示，不追求语言学准确性。

分步实现 ​

第一步：编写核心逻辑与绑定 ​

rust
use std::collections::{HashMap, HashSet};
use wasm_bindgen::prelude::*;

#[wasm_bindgen]
pub struct Stats { chars: u32, words: u32, unique_words: u32, minutes: f64, top: Vec<String> }
#[wasm_bindgen]
impl Stats {
    #[wasm_bindgen(getter)] pub fn chars(&self) -> u32 { self.chars }
    #[wasm_bindgen(getter)] pub fn words(&self) -> u32 { self.words }
    #[wasm_bindgen(getter)] pub fn unique_words(&self) -> u32 { self.unique_words }
    #[wasm_bindgen(getter)] pub fn minutes(&self) -> f64 { self.minutes }
    #[wasm_bindgen(getter)] pub fn top(&self) -> Vec<String> { self.top.clone() }
}
fn tokenize(text: &str) -> Vec<String> {
    text.split_whitespace()
        .map(|word| word.trim_matches(|c: char| !c.is_alphanumeric()).to_lowercase())
        .filter(|word| !word.is_empty())
        .collect()
}
#[wasm_bindgen]
pub fn analyze(text: &str, limit: u32) -> Stats {
    let tokens = tokenize(text);
    let unique: HashSet<&str> = tokens.iter().map(String::as_str).collect();
    let mut counts: HashMap<&str, u32> = HashMap::new();
    for token in &tokens {
        *counts.entry(token.as_str()).or_insert(0) += 1;
    }
    let mut pairs: Vec<(&str, u32)> = counts.into_iter().collect();
    pairs.sort_by(|a, b| b.1.cmp(&a.1).then_with(|| a.0.cmp(b.0)));
    Stats {
        chars: text.chars().filter(|c| !c.is_whitespace()).count() as u32,
        words: tokens.len() as u32,
        unique_words: unique.len() as u32,
        minutes: tokens.len() as f64 / 200.0,
        top: pairs.into_iter().take(limit as usize).map(|(word, _)| word.to_string()).collect(),
    }
}

#[wasm_bindgen] 是属性宏（attribute macro）：加在 struct 上生成 JavaScript 可见的类，加在 impl 上导出方法，加在 pub fn 上导出函数。字符串参数使用 &str 即可，胶水代码（glue code）负责在 JS 字符串与 WASM 线性内存之间复制。

导出结构体的字段默认私有，因此需要 getter 才能从 JS 读取；这类对象由 JS 侧持有，不再使用时应调用 stats.free() 释放 WASM 内存。

}

第四步：用标准库模拟核心逻辑 ​

WASM 只是编译目标，统计逻辑可以在本机用纯 Rust 验证。下面的示例复现分词、去重与排序过程，输出与浏览器端一致。

文本统计核心逻辑Rust 2021
use std::collections::{HashMap, HashSet};

fn tokenize(text: &str) -> Vec<String> {
    text.split_whitespace()
        .map(|word| word.trim_matches(|c: char| !c.is_alphanumeric()).to_lowercase())
        .filter(|word| !word.is_empty())
        .collect()
}
fn main() {
    let text = "Rust makes systems programming safer. Rust also makes it faster. Safety and speed are not opposites.";
    let tokens = tokenize(text);
    let unique: HashSet<&str> = tokens.iter().map(String::as_str).collect();
    let mut counts: HashMap<&str, usize> = HashMap::new();
    for token in &tokens {
        *counts.entry(token.as_str()).or_insert(0) += 1;
    }
    let mut pairs: Vec<(String, usize)> =
        counts.into_iter().map(|(word, n)| (word.to_string(), n)).collect();
    pairs.sort_by(|a, b| b.1.cmp(&a.1).then_with(|| a.0.cmp(&b.0)));
    println!("字符数: {}", text.chars().filter(|c| !c.is_whitespace()).count());
    println!("词数: {}", tokens.len());
    println!("去重词数: {}", unique.len());
    println!("阅读时长: {:.1} 分钟", tokens.len() as f64 / 200.0);
    for (word, count) in pairs.iter().take(3) {
        println!("{word:<8}{count}");
    }
}

测试与部署 ​

统计与排序是纯函数，直接在本机运行 cargo test 即可，无需浏览器：

rust
#[cfg(test)]
mod tests {
    use super::*;
    #[test]
    fn tokenize_and_analyze() {
        let text = "Rust rust; WASM.";
        assert_eq!(tokenize(text), vec!["rust", "rust", "wasm"]);
        let stats = analyze(text, 1);
        assert_eq!((stats.words, stats.unique_words), (3, 2));
        assert_eq!(stats.top, vec!["rust"]);
    }
}

练习

增加导出函数 longest_word(text: &str) -> String，返回文本中最长的词；长度相同时返回字母序靠前者，并接入页面展示。

参考答案

复用 tokenize，用 tokens.iter().max_by(|a, b| a.len().cmp(&b.len()).then_with(|| b.cmp(a))) 取最长词。长度相同时要让字母序更小的获胜，因此第二段比较需要反向；空文本用 unwrap_or_default() 返回空字符串。

小结 ​

  • wasm-bindgen 生成 JS 与 WASM 之间的绑定代码；crate-type = ["cdylib", "rlib"] 同时满足浏览器加载与本机测试。
  • wasm-pack 的 --target web 产物可直接被 ES module 引入，由 init() 完成实例化。
  • Vite 需要被允许读取 pkg/；部署时确保 .wasm 的 MIME 类型与资源基路径正确。
