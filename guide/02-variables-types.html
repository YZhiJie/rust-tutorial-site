变量、类型与控制流 ​

学习目标

  • 理解变量默认不可变、mut 的作用，以及遮蔽（shadowing）与重新赋值的区别
  • 区分 const 与 static，能正确选择整数、浮点、布尔与字符类型
  • 会使用元组（tuple）与数组（array），并用 checked_*、wrapping_* 等方法处理整数溢出（integer overflow）
  • 把 if、loop、while、for 当作表达式（expression）使用

问题背景：默认不可变带来的确定性 ​

Rust 把「变量默认不可变」作为语言规则，而不是编码风格建议。这样编译器可以确认一个值在作用域内何时被修改，从而支撑借用检查（borrow checking）与并发安全。需要修改时，用 mut 显式声明意图；如果只是想在同一个名字下换一个值，则使用遮蔽生成新的绑定。读代码时因此不必追踪整个函数，就能知道某个变量是否可能被改写。

let、mut 与遮蔽 ​

可变绑定、常量与遮蔽Rust 2021
const MAX_RETRY: u32 = 3;
static APP_NAME: &str = "demo";

fn main() {
    let level = 1;
    // level = 2; // error[E0384]: cannot assign twice to immutable variable
    println!("{APP_NAME} 初始等级 {level}");

    let mut score = 10;
    score += 5;
    println!("score = {score}");

    let level = level + 1; // 遮蔽：产生新的不可变绑定
    let level = level * 10;
    println!("遮蔽后的 level = {level}");

    println!("MAX_RETRY = {MAX_RETRY}");
}

  • 不可变绑定（immutable binding）：let level = 1; 之后不能对 level 赋值，否则触发 E0384。
  • 可变绑定（mutable binding）：let mut score 允许修改，但同一作用域内仍只能有一个可变绑定。
  • 遮蔽（shadowing）：let level = ... 复用名字创建新绑定，新绑定可以与旧绑定类型不同。旧值通常在最后一次使用后结束生命周期，而不是被修改。

const 与 static 都在编译期求值，但 const 可内联、没有固定地址，static 全局唯一且有固定地址。两者都必须标注类型并初始化为编译期常量；static 默认只读，可变静态变量 static mut 需要 unsafe 访问。

标量类型 ​

Rust 的标量类型（scalar types）分为四类：

类别类型说明
有符号整数i8 i16 i32 i64 i128 isize默认 i32，isize 随指针宽度变化
无符号整数u8 u16 u32 u64 u128 usize索引用 usize
浮点数f32 f64默认 f64，遵循 IEEE 754
布尔与字符bool charbool 只有 true/false；char 占 4 字节，表示一个 Unicode 标量值

char 固定占 4 字节，i32 占 4 字节，u8 占 1 字节，usize 的宽度与平台指针一致（64 位平台为 8 字节）。数字字面量可以加下划线分组（9_000_000_000），也可以带类型后缀（42u8、1.5f32）。Rust 不做隐式数值转换，i32 与 f64 不能直接运算。

元组与数组 ​

元组（tuple）把不同类型的值组合成固定长度的整体；数组（array）要求元素类型相同、长度固定，数据直接存放在栈上。

元组与数组Rust 2021
fn main() {
    let point: (i32, i32) = (3, -4);
    let (x, y) = point; // 解构
    println!("x = {x}，y = {y}，point.0 = {}", point.0);

    let mut scores: [i32; 3] = [90, 85, 77];
    scores[1] = 88;
    let sum: i32 = scores.iter().sum();
    println!("scores = {scores:?}，平均 = {:.2}", sum as f64 / scores.len() as f64);

    let zeros = [0u8; 4]; // 重复初始化
    println!("zeros = {zeros:?}，长度 = {}", zeros.len());
}

元组通过 .0、.1 访问元素；数组通过下标访问，越界会在运行时 panic。数组的长度属于类型的一部分：[i32; 3] 与 [i32; 4] 是不同类型。需要动态长度时使用切片（slice）或 Vec<T>，后续章节展开。

整数溢出 ​

整数溢出（integer overflow）发生在结果超出类型可表示范围时。debug 构建默认在溢出时 panic；release 构建默认按二进制补码回绕（wrap），但不应依赖这一行为。需要明确语义时，使用标准库提供的方法：

方法返回值行为
checked_addOption<T>溢出返回 None
wrapping_addT溢出回绕
saturating_addT溢出时停在边界值
overflowing_add(T, bool)返回值与是否溢出
整数溢出的四种处理方式Rust 2021
fn main() {
    let max = i32::MAX;

    println!("checked_add(1): {:?}", max.checked_add(1));
    println!("checked_add(-1): {:?}", max.checked_add(-1));
    println!("wrapping_add(1): {}", max.wrapping_add(1));
    println!("saturating_add(1): {}", max.saturating_add(1));
    println!("overflowing_add(1): {:?}", max.overflowing_add(1));
}

注意 max + 1 这类直接运算在 debug 构建中会 panic（attempt to add with overflow），release 构建则回绕。对来自外部输入或计算结果可能越界的场景，优先使用 checked_* 并显式处理 None，而不是依赖 release 下的回绕。

类型推断与 as 转换 ​

类型推断（type inference）会沿着赋值、函数调用和返回值传播。推断不出，或需要覆盖默认值时，使用类型标注（type annotation），例如 let values: Vec<u8> = Vec::new();——Vec::new() 没有元素，不标注就无法确定元素类型。

as 执行显式转换（cast），对数值类型可能丢失信息：整数降级会截断高位，浮点转整数向零取整，超出范围时自 Rust 1.45 起饱和到边界值。

rust
let byte = 300i32 as u8;     // 44，截断
let int = 3.99_f64 as i32;   // 3，向零取整
let max = 1.0e10_f64 as i32; // 2147483647，饱和

控制流是表达式 ​

if、loop、while、for 都有值。if 的两个分支必须产生相同类型；条件必须是 bool，不存在「非零即真」的隐式判断。loop 可以通过 break value 把值带出循环。

if、loop、while 与 forRust 2021
fn main() {
    let n = 7;
    let parity = if n % 2 == 0 { "偶数" } else { "奇数" };
    println!("{n} 是{parity}");

    let mut count = 0;
    let square = loop {
        count += 1;
        if count * count > 50 {
            break count * count; // break 带值，作为 loop 的结果
        }
    };
    println!("第一个平方超过 50 的数是 {count}，平方为 {square}");

    let mut sum = 0;
    let mut i = 1;
    while i <= 10 {
        sum += i;
        i += 1;
    }
    println!("1 到 10 求和 = {sum}");

    for i in (1..=5).rev() {
        print!("{i} ");
    }
    println!();
}

范围（range）有两种：a..b 左闭右开，a..=b 两端都包含。for 遍历的是 IntoIterator 的产物；数组在 Rust 2021 中按值遍历，元素为 Copy 时原数组仍可用。

rust

    let total = 0;
    let total = total + 1;
    total += 1; // error[E0384]: cannot assign twice to immutable variable

练习 ​

练习

使用 for 和 if/else if 打印 1 到 30 的 FizzBuzz：能被 3 整除输出 Fizz，能被 5 整除输出 Buzz，同时被 3 和 5 整除输出 FizzBuzz，其余输出数字本身。再完成温度转换：遍历 [20.0, 25.5, 18.0]，输出对应的华氏温度，保留一位小数。

参考答案
FizzBuzz 参考答案Rust 2021
fn main() {
    for n in 1..=30 {
        if n % 15 == 0 {
            println!("FizzBuzz");
        } else if n % 3 == 0 {
            println!("Fizz");
        } else if n % 5 == 0 {
            println!("Buzz");
        } else {
            println!("{n}");
        }
    }

    let celsius = [20.0, 25.5, 18.0];
    for c in celsius {
        let f = c * 9.0 / 5.0 + 32.0;
        println!("{c:.1}°C = {f:.1}°F");
    }
}

小结 ​

  • 变量默认不可变；mut 表示允许修改，遮蔽则创建新绑定。
  • const 在编译期内联，static 有固定地址；标量类型之间不会隐式转换，as 可能截断或饱和。
  • 整数溢出在 debug 下 panic、release 下回绕；if、loop 是表达式，loop 可用 break value 返回值。
