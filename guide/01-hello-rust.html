第一个 Rust 程序 ​

学习目标

  • 看懂一个最小 Rust 程序的每个组成部分
  • 理解 rustc 与 cargo 各自负责什么
  • 掌握 println! 的常用格式化写法

Hello, Rust ​

先运行第一个示例，再逐行拆解。

Hello, RustRust 2021
fn main() {
    let name = "Rust";
    println!("Hello, {name}!");
    println!("1 + 2 = {}", 1 + 2);
}
在 Playground 打开 ↗
等待运行
点击「运行」，编译输出与程序结果会显示在这里。

点击「运行」后，stdout 中应出现两行输出。stderr 里的 Compiling、Finished、Running 是编译器的工作日志，不是错误。

这段代码包含三个关键点：

  1. fn main() 是程序入口。Rust 可执行程序必须有一个 main 函数，返回类型可以省略（等价于返回 ()）。
  2. let name = "Rust"; 声明一个变量，类型由编译器推断为 &str（字符串切片）。
  3. println! 末尾的 ! 表示它是宏，不是普通函数。宏会在编译期展开，因此可以接受可变数量的参数并做格式检查。

编译与运行 ​

Rust 是提前编译（AOT）的语言。一个 .rs 文件先被编译成机器码，再执行：

bash
rustc main.rs
./main
1
2

但在真实项目中，我们几乎总是使用 Cargo：

bash
cargo new hello_rust   # 创建项目
cd hello_rust
cargo run              # 编译并运行
cargo build            # 只编译，产物在 target/debug/
cargo build --release  # 优化编译，产物在 target/release/

Cargo 负责依赖解析、编译参数、产物目录与增量构建。cargo run 并不是解释执行，它只是把“编译 + 运行”合并成一条命令。

println! 的格式化 ​

println! 使用格式字符串，{} 是占位符。常用能力如下：

格式化输出Rust 2021
fn main() {
    let pi = 3.14159;
    let name = "Rust";
    let year = 2015;

    println!("默认: {pi}");
    println!("两位小数: {pi:.2}");
    println!("调试输出: {pi:?}");
    println!("右对齐宽度 8: |{pi:>8.2}|");
    println!("左侧标签: {name:<8}|");
    println!("内插表达式: {}", year + 10);
}
在 Playground 打开 ↗
等待运行
点击「运行」，编译输出与程序结果会显示在这里。

几个容易混淆的点：

  • {} 走 Display，适合面向用户的输出；{:?} 走 Debug，适合调试。
  • {pi} 这种“变量直接内插”写法要求变量在当前作用域内可见。
  • {:.2} 对浮点数表示保留两位小数，对字符串则表示最多显示两个字符。
  • 格式字符串在编译期检查；占位符数量和参数类型不匹配会直接编译失败。

一个稍完整的例子 ​

下面把变量、格式化与简单计算放在一起。试着修改 price 和 count，观察输出变化。

计算订单总价Rust 2021
fn main() {
    let price = 29.9;
    let count = 3;
    let discount = 0.85;

    let subtotal = price * count as f64;
    let total = subtotal * discount;

    println!("单价: {price:.2} 元");
    println!("数量: {count}");
    println!("小计: {subtotal:.2} 元");
    println!("折后: {total:.2} 元");
}
在 Playground 打开 ↗
等待运行
点击「运行」，编译输出与程序结果会显示在这里。

这里出现了 count as f64。Rust 不会隐式转换数值类型，i32 与 f64 不能直接相乘，必须显式转换。这是 Rust 保证可预测性的方式之一，后续章节会反复遇到。

练习

打印一张个人信息卡片，要求：姓名左对齐占 10 个字符、年龄占 3 个字符、城市右对齐占 12 个字符；数字保留两位小数。

参考答案
个人信息卡片Rust 2021
fn main() {
    let name = "Ada";
    let age = 36;
    let city = "London";
    let score = 98.765;

    println!("|{name:<10}|{age:>3}|{city:>12}|");
    println!("|{:<10}|{:>3}|{:>12.2}|", "score", "", score);
}

小结 ​

  • fn main() 是入口，println! 是宏。
  • Rust 先编译后运行；日常使用 cargo run。
  • {} 是 Display，{:?} 是 Debug；格式在编译期检查。
  • 数值类型不会隐式转换，需要 as 或显式构造。
