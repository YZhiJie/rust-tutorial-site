集合与迭代器 ​

学习目标

  • 使用 Vec<T> 增删元素，并区分索引访问与 get 的失败行为
  • 理解 String 与 &str 的关系、UTF-8 边界与所有权转移
  • 用 HashMap、BTreeMap、HashSet 组织键值数据，掌握 entry API
  • 分清 iter、iter_mut、into_iter，并用 map/filter/collect/fold 组合计算

问题背景 ​

数组长度在编译期固定，无法承载运行时才确定的数据量。标准库提供了一组堆分配的集合（collection）：Vec<T> 是有序可变长序列，String 是 UTF-8 文本，HashMap/BTreeMap 保存键值对，HashSet 保存不重复的值。它们的共同点是拥有自己的元素，因此元素的增删与遍历都必须符合所有权（ownership）和借用（borrowing）规则。

Vec：可变长序列 ​

Vec<T> 在堆上连续存储元素，长度可变。push 在末尾追加，insert 在指定位置插入，pop 移除并返回末尾元素。索引语法 v[i] 在越界时直接 panic；v.get(i) 返回 Option<&T>，适合处理不可信下标。

Vec 的增删与遍历Rust 2021
fn main() {
    let mut scores = vec![72, 88, 95];
    scores.push(60);
    scores.insert(1, 80);
    println!("长度: {}", scores.len());
    match scores.get(10) {
        Some(value) => println!("第 11 项: {value}"),
        None => println!("索引越界，get 返回 None"),
    }

    let mut total = 0;
    for score in &scores {
        total += score;
    }
    println!("总分: {total}");

    for score in &mut scores {
        *score += 5;
    }
    println!("加分后: {scores:?}");
    println!("弹出: {:?}", scores.pop());
}

for score in &scores 借用元素，集合仍可使用；&mut scores 允许原地修改，循环变量是 &mut i32，需要解引用后才能赋值。Vec 的容量（capacity）由实现按增长策略分配，不应依赖具体数值。

String 与 &str ​

String 拥有堆上的 UTF-8 缓冲区，可增长；&str 是对某段 UTF-8 字节的借用切片，长度固定。函数参数优先使用 &str，因为它同时接受 &String（通过解引用强制转换）与字符串字面量。

String 与 &strRust 2021
fn greet(name: &str) -> String {
    format!("你好，{name}！")
}

fn main() {
    let mut title = String::from("Rust");
    title.push_str(" 教程");
    title.push('！');

    let slice: &str = &title[..4];
    println!("{}", greet(slice));
    println!("字符数 {}，字节数 {}", title.chars().count(), title.len());
    let words = ["所有权", "借用", "生命周期"];
    println!("{}", words.join("、"));
}

title.len() 返回字节数而不是字符数，中文通常占 3 个字节。按字节下标切片时，边界必须落在字符边界上，否则运行时 panic；遍历字符应使用 chars()，定位字节位置应使用 char_indices()。

String 赋值会移动所有权：let b = a; 之后 a 不可再用；需要两份数据时使用 a.clone()。format! 与 push_str 不会消耗原字符串。

HashMap、BTreeMap 与 HashSet ​

HashMap<K, V> 要求键实现 Eq + Hash，查找平均 O(1)，遍历顺序不保证；BTreeMap<K, V> 要求键实现 Ord，按 key 有序，适合需要稳定输出的场景。HashSet<T> 是只保存键的哈希表，用于去重与成员判断。

用 HashMap 统计词频Rust 2021
use std::collections::{BTreeMap, HashMap};

fn main() {
    let text = "the quick brown fox jumps over the lazy dog the fox";
    let mut counts: HashMap<&str, usize> = HashMap::new();

    for word in text.split_whitespace() {
        *counts.entry(word).or_insert(0) += 1;
    }

    println!("the: {}", counts["the"]);
    println!("fox: {:?}", counts.get("fox"));
    println!("cat: {:?}", counts.get("cat"));
    let sorted: BTreeMap<&str, usize> = counts.iter().map(|(k, v)| (*k, *v)).collect();
    for (word, count) in &sorted {
        println!("{word}: {count}");
    }
}

entry API 只查找一次：or_insert(0) 在键不存在时插入默认值，并返回 &mut V，因此可以直接累加。and_modify(|v| ...).or_insert(...) 可在命中与未命中时执行不同逻辑。counts["cat"] 在键不存在时会 panic，不确定键是否存在时必须用 get。

HashSet 的常用操作是 insert（返回 bool 表示是否新增）、contains 与 remove。集合中的元素必须可哈希；f64 未实现 Hash，不能直接作为 HashMap 的键。

集合中的所有权与三种迭代 ​

集合拥有其元素，遍历方式决定拿到的是引用还是所有权：

写法迭代器元素类型集合之后能否使用
&v / v.iter()Iter&T可以
&mut v / v.iter_mut()IterMut&mut T可以，需结束借用
v / v.into_iter()IntoIterT不可以，已被消耗

v[0] 只产生借用，不能把元素移动出来；需要所有权时使用 into_iter()、remove 或 swap_remove。迭代器适配器（adapter）如 map、filter、take 是惰性的，只有遇到 collect、sum、fold 或 for 循环时才真正执行。

iter、iter_mut 与 into_iterRust 2021
fn main() {
    let numbers = vec![1, 2, 3, 4, 5, 6];

    let doubled: Vec<i32> = numbers.iter().map(|n| n * 2).collect();
    println!("翻倍: {doubled:?}");

    let even_sum: i32 = numbers.iter().filter(|n| *n % 2 == 0).sum();
    println!("偶数和: {even_sum}");

    let product = numbers.iter().fold(1, |acc, n| acc * n);
    println!("连乘: {product}");

    let mut words = vec![String::from("b"), String::from("a")];
    for word in &mut words {
        word.push('!');
    }
    println!("修改后: {words:?}");

    let owned: Vec<String> = words.into_iter().map(|w| w.to_uppercase()).collect();
    println!("消耗后: {owned:?}");
    let lazy = numbers.iter().map(|n| {
        println!("计算 {n}");
        n * n
    });
    println!("map 尚未执行");
    let first_three: Vec<i32> = lazy.take(3).collect();
    println!("前三个平方: {first_three:?}");
}

练习

统计一段文本的词频，忽略大小写与标点，返回出现次数最多的前 K 个单词。要求使用 HashMap 计数，排序后截取前 K 项，并对并列次数按单词字典序排序。

参考答案
参考答案：Top-K 词频Rust 2021
use std::collections::HashMap;

fn top_k(text: &str, k: usize) -> Vec<(String, usize)> {
    let mut counts: HashMap<String, usize> = HashMap::new();
    for raw in text.split_whitespace() {
        let word: String = raw.chars().filter(|c| c.is_alphanumeric()).collect::<String>().to_lowercase();
        if !word.is_empty() {
            *counts.entry(word).or_insert(0) += 1;
        }
    }

    let mut items: Vec<(String, usize)> = counts.into_iter().collect();
    items.sort_by(|a, b| b.1.cmp(&a.1).then(a.0.cmp(&b.0)));
    items.truncate(k);
    items
}

fn main() {
    let text = "Rust rust rust GO go Python python python";
    for (rank, (word, count)) in top_k(text, 3).iter().enumerate() {
        println!("{}. {word}: {count}", rank + 1);
    }
}

小结 ​

  • Vec<T> 拥有元素，v[i] 越界会 panic，get 返回 Option。
  • String 拥有 UTF-8 缓冲区，&str 是借用切片；len 是字节数，chars 才是字符。
  • HashMap 无序且要求 Eq + Hash，BTreeMap 按键有序且遍历稳定；entry 只查找一次。
  • iter/iter_mut 借用，into_iter 消耗集合；适配器惰性执行，遇到消费型方法才运行。
