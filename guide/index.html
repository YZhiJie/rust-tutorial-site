  • 理解六个阶段的学习顺序，以及每个阶段要解决的问题

  • 学会使用本站的在线编辑器：修改、运行、重置、查看编译输出

一条主线，而不是语法清单 ​

Rust 的学习难点从来不是“语法多”，而是编译器对内存与并发的约束。如果按变量、循环、函数、结构体的顺序死记，很容易出现“每句都看懂，合起来写不出”的状态。

本站围绕一条主线组织内容：

值的归属 → 谁可以借用 → 借用活多久 → 如何用 trait 表达行为 → 如何安全地并发与异步 → 如何组织成工程。

前三个阶段建立这套心智模型，后三个阶段把它落到并发、异步与真实项目。

环境准备 ​

方式一：只使用在线示例 ​

本站每个核心示例都可以直接在浏览器中编辑运行，执行环境是官方 Rust Playground。开始学习不需要安装任何东西，只需要网络。

方式二：本地安装工具链（推荐） ​

bash
# macOS / Linux
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Windows：从 https://rustup.rs 下载安装程序

# 安装后确认版本

怎么使用在线示例 ​

每个示例右上角标有 Rust 2021，表示使用的 edition。操作方式：

  1. 运行：点击「运行」或按 ⌘/Ctrl + Enter，代码会发送到 Playground 编译执行；
  2. 编辑：直接修改代码，再次运行即可看到新结果；
  3. 重置：恢复示例的初始代码；
  4. 在 Playground 打开：在新标签页中打开完整 Playground，适合需要添加依赖或调试较长代码时使用。

输出区分两段：

  • 上方是程序标准输出（stdout）；
  • 下方是编译器与运行时信息（stderr），包括警告、错误与 panic 信息。

在线执行依赖外部服务。若遇到网络失败或限流，请稍后重试，或使用本地环境运行同样的代码。

学习建议 ​

  1. 不要只看不写。 每读一个示例，至少改一处再运行一次。
  2. 主动制造错误。 把 let 改成 let mut 的反面、删掉 &、提前释放值，观察编译器如何解释。
  3. 先读报错再搜索。 Rust 的错误信息通常包含修复建议，--help 提示往往直接给出答案。
  4. 每章完成练习再进入下一章。 练习是检验“能否独立写出”的唯一标准。

开始之前 ​

确认下面三件事，然后进入第一章：

  • [ ] 我能说清楚“编译型语言”和“解释型语言”的区别
  • [ ] 我已经决定使用在线示例还是本地工具链
  • [ ] 我知道 cargo run 会依次完成编译与运行
