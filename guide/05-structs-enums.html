结构体、枚举与模式匹配 ​

学习目标

  • 区分具名结构体（named struct）、元组结构体（tuple struct）与单元结构体（unit struct）
  • 会编写 impl 方法（method）与关联函数（associated function）
  • 理解枚举（enum）携带数据的方式，以及 Option<T> 如何表达“可能没有值”
  • 掌握 match 守卫、绑定与 if let、while let、let else

问题背景 ​

标量类型只能表达单个值，而真实数据往往由多个字段共同构成一个实体，状态也通常只在有限几个选项中出现。若用彼此独立的变量表示，编译器既无法保证字段齐全，也无法保证分支覆盖完整。结构体（struct）表达“同时具有这些字段”，枚举（enum）表达“只能是其中一种形态”，模式匹配（pattern matching）则在使用时安全地拆开它们。

三种结构体 ​

rust
struct User {          // 具名结构体：字段有名字
    name: String,
    active: bool,
}

struct Point(f64, f64); // 元组结构体：字段靠位置访问
struct Marker;          // 单元结构体：不携带数据，常用于标记类型

impl：方法与关联函数 ​

impl 块定义类型的行为。第一个参数为 self、&self 或 &mut self 的函数是方法，用 value.method() 调用；没有 self 的是关联函数，用 Type::function() 调用。Self 指当前类型，选择 &self 还是 &mut self 会直接影响调用方是否需要可变绑定。

#[derive(...)] 让编译器自动生成 trait 实现：Debug 支持 {:?}，Clone 提供 clone()，PartialEq 支持 ==。派生要求所有字段都实现对应 trait。

结构体、方法与关联函数Rust 2021
#[derive(Debug, Clone, PartialEq)]
struct Rectangle {
    width: f64,
    height: f64,
}

impl Rectangle {
    fn new(width: f64, height: f64) -> Self {
        Self { width, height }
    }

    fn area(&self) -> f64 {
        self.width * self.height
    }
    fn scale(&mut self, factor: f64) {
        self.width *= factor;
        self.height *= factor;
    }
}
fn main() {
    let mut rect = Rectangle::new(3.0, 4.0);
    println!("初始: {rect:?}，面积 {}", rect.area());
    let copy = rect.clone();
    rect.scale(2.0);
    println!("缩放后: {rect:?}");
    println!("副本: {copy:?}，相等 {}", rect == copy);
}

Option 与空值 ​

标准库的 Option<T> 只有 None 与 Some(T) 两个变体，位于预导入模块中。Rust 没有空指针，需要“缺失”语义时一律使用 Option，调用方必须显式处理 None。

match、守卫与绑定 ​

match 逐个比较模式，且必须覆盖所有可能情况。模式可以是字面量、变体解构或 _；守卫（guard）以 if 追加条件；绑定（binding）用 value @ 1..=9 同时匹配范围并绑定值。

枚举、match 与 OptionRust 2021
#[derive(Debug)]
enum Shape {
    Circle { radius: f64 },
    Rect(f64, f64),
    Empty,
}
fn area(shape: &Shape) -> Option<f64> {
    match shape {
        Shape::Circle { radius } if *radius > 0.0 => {
            Some(std::f64::consts::PI * radius * radius)
        }
        Shape::Rect(w, h) if *w > 0.0 && *h > 0.0 => Some(w * h),
        _ => None,
    }
}
fn main() {
    let shapes = [
        Shape::Circle { radius: 1.5 },
        Shape::Rect(2.0, 5.0),
        Shape::Empty,
    ];

    for shape in &shapes {
        match area(shape) {
            Some(value) => println!("{shape:?} 的面积是 {value:.2}"),
            None => println!("{shape:?} 没有有效面积"),
        }
    }

    if let Shape::Rect(w, h) = &shapes[1] {
        println!("第二个是矩形，宽 {w}，高 {h}");
    }

    for n in [0, 3, 42] {
        let label = match n { 0 => "零", v @ 1..=9 => if v % 2 == 0 { "小偶数" } else { "小奇数" }, _ => "大数" };
        println!("{n}: {label}");
    }
}

if let、while let 与 let else ​

只关心一个分支时用 if let；模式持续匹配时用 while let；let else 适合“匹配失败就提前退出”，其 else 分支必须发散（return、break 或 panic!），否则后续代码中的绑定无法保证有效。

while let 与 let elseRust 2021
fn main() {
    let mut stack = vec![1, 2, 3];
    while let Some(top) = stack.pop() {
        println!("弹出: {top}");
    }
    let Ok(port) = "8080".parse::<u16>() else {
        println!("端口无效");
        return;
    };
    println!("端口: {port}");
}

练习

定义枚举 Shape，包含圆、矩形、三角形；实现 area 与 name，遍历形状输出名称与面积，并求总面积。要求用 match 解构字段。

参考答案
参考答案：形状面积Rust 2021
enum Shape {
    Circle { radius: f64 },
    Rectangle { width: f64, height: f64 },
    Triangle { base: f64, height: f64 },
}
impl Shape {
    fn area(&self) -> f64 {
        match self {
            Shape::Circle { radius } => std::f64::consts::PI * radius * radius,
            Shape::Rectangle { width, height } => width * height,
            Shape::Triangle { base, height } => 0.5 * base * height,
        }
    }
    fn name(&self) -> &'static str {
        match self {
            Shape::Circle { .. } => "圆",
            Shape::Rectangle { .. } => "矩形",
            Shape::Triangle { .. } => "三角形",
        }
    }
}

fn main() {
    let shapes = [
        Shape::Circle { radius: 1.5 },
        Shape::Rectangle { width: 2.0, height: 5.0 },
        Shape::Triangle { base: 4.0, height: 3.0 },
    ];
    for shape in &shapes {
        println!("{}: {:.2}", shape.name(), shape.area());
    }
    let total: f64 = shapes.iter().map(Shape::area).sum();
    println!("总面积: {total:.2}");
}

小结 ​

  • 结构体表达“同时具有”，枚举表达“其中之一”。
  • impl 中带 self 的是方法，不带的是关联函数；derive(Debug, Clone, PartialEq) 支持调试输出、复制与相等比较。
  • Option<T> 替代空值，match 必须穷尽。
  • if let 处理单分支，while let 处理循环，let else 用于失败即退出。
