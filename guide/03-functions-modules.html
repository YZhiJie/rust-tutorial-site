函数、模块与 Cargo ​

学习目标

  • 读懂函数签名，区分表达式（expression）与语句（statement），正确使用尾表达式
  • 用 mod、pub、use 组织模块、路径与文件模块
  • 会编辑 Cargo.toml，使用依赖、profile 与常用 Cargo 命令

问题背景：代码开始变长之后 ​

一个 main.rs 写到几百行时，函数调用关系会变得难以追踪，复用也无从谈起。Rust 提供的组织手段有两层：函数负责把一段逻辑命名并隔离，模块（module）负责把一组相关项归入命名空间并控制可见性。Cargo 则把这些文件、依赖与编译选项组合成一个可构建的包（package）。

函数签名与尾表达式 ​

函数签名（signature）由名字、参数列表与返回类型组成。参数必须标注类型；返回类型省略时等价于 ()。

表达式、尾返回值与提前返回Rust 2021
fn double(n: i32) -> i32 {
    n * 2
}

fn classify(n: i32) -> &'static str {
    if n < 0 {
        return "负数";
    }
    if n == 0 {
        "零"
    } else if n < 10 {
        "个位数"
    } else {
        "多位数"
    }
}

fn div_rem(a: i32, b: i32) -> (i32, i32) {
    (a / b, a % b)
}

fn main() {
    println!("double(21) = {}", double(21));
    for n in [-5, 0, 7, 42] {
        println!("classify({n}) = {}", classify(n));
    }
    let (q, r) = div_rem(17, 5);
    println!("17 / 5 = {q} 余 {r}");
}

  • double 的函数体只有一个表达式 n * 2，末尾不加分号，它的值就是返回值。
  • 加分号会把表达式变成语句，函数返回类型随即变成 ()，与声明的 i32 不匹配。
  • return 用于提前结束函数；返回多个值用元组，调用处用模式解构接收。

参数默认按值传递：Copy 类型被复制，String 这类拥有堆数据的类型会发生移动（move）。需要保留所有权时传引用：&String 会自动解引用为 &str（Deref 强制转换），&str 本身是 Copy 的。

模块、可见性与路径 ​

模块可以内联定义，也可以来自文件。默认一切私有，pub 把项暴露给外部；父模块可以访问子模块的公开项，子模块不能访问父模块的私有项。

内联模块、pub 与 useRust 2021
mod geometry {
    pub mod rectangle {
        pub fn area(width: f64, height: f64) -> f64 { width * height }
        pub fn perimeter(width: f64, height: f64) -> f64 { 2.0 * (width + height) }
    }

    pub fn describe(width: f64, height: f64) -> String {
        format!("面积 {:.2}，周长 {:.2}", rectangle::area(width, height), rectangle::perimeter(width, height))
    }
}

use geometry::rectangle;

fn main() {
    let (w, h) = (3.0, 4.5);
    println!("{}", geometry::describe(w, h));
    println!("面积 = {:.2}", rectangle::area(w, h));
}

路径（path）有三种起点：crate:: 表示当前包根，self:: 表示当前模块，super:: 表示父模块。use 只把路径引入当前作用域，不改变可见性；公开 API 仍需 pub。

文件模块 ​

  • [dependencies] 是运行时依赖；[dev-dependencies] 只用于测试、示例与基准。
  • 版本 "1" 等价于 ^1，允许升级到 1.x 的最新兼容版本；精确锁定写 =1.2.3。Cargo.lock 记录实际解析出的版本，可执行程序应提交它，库通常不提交。
  • [profile.release] 覆盖优化等级与链接时优化（LTO），代价是编译更慢。

常用 Cargo 命令 ​

bash
cargo new wordcount --bin  # 新建可执行项目
cargo check                # 只做类型检查，比 build 快
cargo run                  # 编译并运行
cargo test                 # 运行测试
cargo clippy -- -D warnings # 静态检查，警告视为错误
cargo build --release      # 优化构建

常见错误 ​

尾表达式加分号，是类型不匹配的高频原因：

rust
fn double(n: i32) -> i32 {
    n * 2; // error[E0308]: mismatched types，expected `i32`, found `()`
}

模块内的项默认私有，外部调用需要 pub，否则会出现 error[E0603]: function ... is private。若声明了 mod utils; 但 src/utils.rs 与 src/utils/mod.rs 都不存在，编译器会报 E0583: file not found for module。

练习

把下面的单文件程序拆成 src/main.rs、src/convert.rs 与 src/stats.rs：转换函数放进 convert，统计函数放进 stats，main 只负责调用，输出保持不变。

rust
fn celsius_to_fahrenheit(c: f64) -> f64 {
    c * 9.0 / 5.0 + 32.0

fn average(values: &[f64]) -> f64 {
    values.iter().sum::<f64>() / values.len() as f64
}

fn main() {
    let temps = [20.0, 25.5, 18.0, 30.0];
    for t in temps {
        println!("{t}°C = {:.1}°F", celsius_to_fahrenheit(t));

    println!("平均温度: {:.2}°C", average(&temps));
}

调用处可加 use convert::celsius_to_fahrenheit; 与 use stats::average; 缩短路径。文件模块的公开项仍需 pub，否则父模块无法访问。

小结 ​

  • 函数体最后一个表达式不加分号即为返回值；mod 定义模块，pub 控制可见性，use 简化路径。
  • 文件模块通过 mod name; 声明，对应 name.rs 或 name/mod.rs。
  • Cargo.toml 管理依赖与构建 profile，Cargo.lock 锁定实际版本。
