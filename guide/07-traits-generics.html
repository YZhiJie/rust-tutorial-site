trait、泛型与 trait 对象 ​

学习目标

  • 定义 trait、为类型实现 trait，并用默认方法复用逻辑
  • 掌握 trait bound、泛型函数、泛型结构体与 impl Trait
  • 理解单态化（monomorphization）与动态分发的差异
  • 区分 &dyn Trait 与 Box<dyn Trait>，并判断对象安全（object safety）

问题背景 ​

多个类型可能提供同一类行为，例如圆、矩形、三角形都能计算面积。若为每种类型各写一个函数，调用方就必须知道具体类型，也无法把不同类型的值放进同一个集合。trait 用方法签名描述共享行为，泛型（generic）在编译期适配具体类型，trait 对象（trait object）则擦除具体类型，换取运行时的异构集合。

trait 定义与实现 ​

trait 是一组方法签名的集合。实现时使用 impl Trait for Type，必须提供所有没有默认实现的方法；有默认实现的方法可以沿用，也可以覆盖。

trait、默认方法与实现Rust 2021
trait Describable {
    fn name(&self) -> &str;
    fn category(&self) -> &str { "未知" }
    fn describe(&self) -> String {
        format!("{}（{}）", self.name(), self.category())
    }
}
struct Book { title: String }
struct Movie { title: String, minutes: u32 }
impl Describable for Book {
    fn name(&self) -> &str { &self.title }
    fn category(&self) -> &str { "书籍" }
}
impl Describable for Movie {
    fn name(&self) -> &str { &self.title }
    fn describe(&self) -> String {
        format!("{}，片长 {} 分钟", self.name(), self.minutes)
    }
}
fn main() {
    let book = Book { title: String::from("Rust 程序设计") };
    let movie = Movie { title: String::from("崛起"), minutes: 120 };
    println!("{}", book.describe());
    println!("{}", movie.describe());
}

泛型函数与泛型结构体 ​

泛型参数写在尖括号中，trait bound 用 T: Bound 或 where T: Bound 声明。编译器在调用点把泛型参数替换为具体类型，这一过程称为单态化（monomorphization）：每个具体类型生成一份专用代码，运行时没有类型检查开销，代价是二进制体积可能增大。

泛型函数、泛型结构体与 trait boundRust 2021
use std::fmt::Display;
struct Pair<T> { first: T, second: T }
impl<T> Pair<T> {
    fn new(first: T, second: T) -> Self { Self { first, second } }
}
impl<T: Display + PartialOrd> Pair<T> {
    fn larger(&self) -> &T {
        if &self.second > &self.first { &self.second } else { &self.first }
    }
    fn show(&self) -> String { format!("({}, {})", self.first, self.second) }
}
fn largest<T: PartialOrd + Copy>(items: &[T]) -> T {
    let mut max = items[0];
    for &item in items {
        if item > max { max = item; }
    }
    max
}
fn main() {
    let ints = Pair::new(10, 42);
    let floats = Pair::new(1.5, 0.5);
    println!("{} 较大: {}", ints.show(), ints.larger());
    println!("{} 较大: {}", floats.show(), floats.larger());
    println!("最大整数: {}", largest(&[3, 9, 2]));
    println!("最大字符: {}", largest(&['a', 'z', 'm']));
}

同一个 Pair<T> 只有在 T: Display + PartialOrd 时才拥有 larger 与 show，这称为条件实现。largest 通过 Copy 从切片复制元素，空切片会触发 items[0] 越界 panic，调用方需要保证非空。

impl Trait ​

impl Trait 在参数位置（fn print(shape: &impl Shape)）等价于泛型参数加 bound；在返回位置（fn make() -> impl Shape）表示返回某个实现了该 trait 的具体类型，但类型对调用方不可见。返回位置的 impl Trait 仍是静态分发，只能返回同一种类型；不同分支要返回不同类型时，必须使用 Box<dyn Shape>。

trait 对象与动态分发 ​

dyn Trait 是动态大小类型（dynamically sized type），不能直接作为局部变量或返回值，必须放在引用或智能指针之后：&dyn Trait 借用已有值，Box<dyn Trait> 拥有堆上的值并适合放入 Vec。方法调用经过虚表（vtable）动态分发（dynamic dispatch），每次调用有一次间接跳转，但同一集合可以容纳不同具体类型。

&dyn 与 Box<dyn>Rust 2021
trait Shape { fn area(&self) -> f64; }

struct Circle { radius: f64 }
struct Square { side: f64 }

impl Shape for Circle {
    fn area(&self) -> f64 { std::f64::consts::PI * self.radius * self.radius }
}

impl Shape for Square {
    fn area(&self) -> f64 { self.side * self.side }
}

fn total(shapes: &[Box<dyn Shape>]) -> f64 {
    shapes.iter().map(|shape| shape.area()).sum()
}

fn main() {
    let boxes: Vec<Box<dyn Shape>> = vec![
        Box::new(Circle { radius: 1.0 }),
        Box::new(Square { side: 2.0 }),
    ];
    println!("总面积: {:.2}", total(&boxes));

    let circle = Circle { radius: 1.5 };
    let borrowed: &dyn Shape = &circle;
    println!("借用调用: {:.2}", borrowed.area());
}

对象安全（object safety）决定 trait 能否变成 dyn Trait：方法不能带自身泛型参数、不能返回 Self、不能要求 Self: Sized，否则报 E0038。带泛型参数的方法可加 where Self: Sized，从而对 trait 对象禁用该方法。

定义 Shape trait，包含 name、area 与带默认实现的 describe；为圆、矩形、三角形实现该 trait，把不同形状放入 Vec<Box<dyn Shape>>，逐个输出描述并求和面积。

trait Shape {
    fn name(&self) -> &str;
    fn area(&self) -> f64;
    fn describe(&self) -> String {
        format!("{}：面积 {:.2}", self.name(), self.area())
    }
}

struct Circle { radius: f64 }
struct Rectangle { width: f64, height: f64 }
struct Triangle { a: f64, b: f64, c: f64 }

impl Shape for Circle {
    fn name(&self) -> &str { "圆" }
    fn area(&self) -> f64 { std::f64::consts::PI * self.radius * self.radius }
}

impl Shape for Rectangle {
    fn name(&self) -> &str { "矩形" }
    fn area(&self) -> f64 { self.width * self.height }
}

impl Shape for Triangle {
    fn name(&self) -> &str { "三角形" }
    fn area(&self) -> f64 {
        let s = (self.a + self.b + self.c) / 2.0;
        (s * (s - self.a) * (s - self.b) * (s - self.c)).sqrt()
    }
}

fn total_area(shapes: &[Box<dyn Shape>]) -> f64 {
    shapes.iter().map(|shape| shape.area()).sum()
}

fn main() {
    let shapes: Vec<Box<dyn Shape>> = vec![
        Box::new(Circle { radius: 1.0 }),
        Box::new(Rectangle { width: 2.0, height: 3.0 }),
        Box::new(Triangle { a: 3.0, b: 4.0, c: 5.0 }),
    ];
    for shape in &shapes { println!("{}", shape.describe()); }
    println!("总面积: {:.2}", total_area(&shapes));
}

小结 ​

  • trait 描述共享行为；实现时用 impl Trait for Type，默认方法可被覆盖。
  • 泛型通过 trait bound 约束能力，单态化让静态分发没有运行时开销。
  • impl Trait 参数位置等价于泛型，返回位置隐藏具体类型且只能返回一种类型。
  • &dyn Trait 借用、Box<dyn Trait> 拥有；两者都通过虚表动态分发。
  • 对象安全要求方法不带自身泛型参数、不返回 Self；否则只能使用泛型。
