智能指针 ​

学习目标

  • 理解智能指针（smart pointer）与普通引用的区别
  • 用 Box<T> 解决递归类型（recursive type）与堆分配
  • 用 Rc<T> 表达共享所有权（ownership），用 RefCell<T> 获得内部可变性
  • 掌握 Deref、Drop 的调用时机与自定义方式

为什么需要智能指针 ​

引用（reference）只借用值，不拥有值，因此编译器要求引用始终短于所有者。但有些场景无法用单一所有者描述：

  • 数据需要放在堆（heap）上，避免栈上过大的值或构造递归结构；
  • 多个部分需要共同拥有同一份数据，且无法确定谁最后释放；
  • 需要在共享值上修改，但借用检查器在编译期无法证明修改是安全的。

智能指针是拥有数据并实现 Deref 与 Drop 的类型。它们像指针一样可以解引用，同时明确负责释放所指向的资源。本章讨论标准库中最常用的四种组合：Box<T>、Rc<T>、RefCell<T> 与 Rc<RefCell<T>>。

Box：把值放到堆上 ​

普通变量的大小必须在编译期确定。递归类型会直接或间接包含自身，若不加包装就会无限展开，编译器因此拒绝定义。Box<T> 在堆上分配值，栈上只保留一个固定大小的指针，从而打断递归。

用 Box 构造递归链表Rust 2021
#[derive(Debug)]
enum List {
    Cons(i32, Box<List>),
    Nil,
}

fn sum(list: &List) -> i32 {
    match list {
        List::Cons(value, tail) => *value + sum(tail),
        List::Nil => 0,
    }
}

fn main() {
    let list = List::Cons(
        1,
        Box::new(List::Cons(2, Box::new(List::Cons(3, Box::new(List::Nil))))),
    );

    println!("{list:?}");
    println!("sum = {}", sum(&list));
}

Box 拥有堆上的值，离开作用域时自动释放，不产生引用计数开销。它也是把大对象移出栈、把 dyn Trait 装箱成 trait 对象（trait object）的常用手段。

Deref 与 Drop ​

Deref 让自定义类型可以像引用一样使用：*value 会调用 deref，方法调用也会自动穿透多层包装。Drop 则在值离开作用域时执行清理代码。两者组合起来，就是“智能”的来源。

自定义包装类型与析构顺序Rust 2021
use std::ops::Deref;

struct Wrapper<T>(T);

impl<T> Deref for Wrapper<T> {
    type Target = T;

    fn deref(&self) -> &T {
        &self.0
    }
}

struct Noisy(&'static str);

impl Drop for Noisy {
    fn drop(&mut self) {
        println!("释放 {}", self.0);
    }
}

fn main() {
    let wrapper = Wrapper(String::from("hello"));
    println!("长度: {}", wrapper.len());

    let _a = Noisy("a");
    let _b = Noisy("b");
    println!("main 结束前");
}

Rc：共享所有权 ​

Rc<T> 是引用计数（reference counting）指针，适用于单线程内多个所有者共享只读数据。Rc::clone 只增加计数，不复制底层值；最后一个所有者销毁时，计数归零并释放数据。

Rc 的共享所有权Rust 2021
use std::rc::Rc;

fn main() {
    let shared = Rc::new(String::from("shared"));
    println!("初始计数: {}", Rc::strong_count(&shared));

    let a = Rc::clone(&shared);
    let b = Rc::clone(&shared);
    println!("克隆后计数: {}", Rc::strong_count(&shared));
    println!("a = {a}");

    drop(b);
    println!("释放 b 后计数: {}", Rc::strong_count(&shared));
}

Rc 只提供不可变访问。若两个 Rc 相互指向，引用计数永远不会归零，形成循环引用（reference cycle），此时需要用 Weak<T> 持有不增加计数的弱引用（weak reference）。

RefCell：内部可变性 ​

借用规则要求“共享不可变，独占可变”，而 Rc 只能提供共享访问。内部可变性（interior mutability）允许在持有不可变引用时修改内部值。RefCell<T> 把借用检查从编译期推迟到运行时：borrow() 返回不可变借用，borrow_mut() 返回可变借用。

把 Rc 与 RefCell 组合，就得到单线程内可共享、可修改的状态：

Rc<RefCell<T>> 共享可变状态Rust 2021
use std::cell::RefCell;
use std::rc::Rc;

fn main() {
    let counter = Rc::new(RefCell::new(0));
    let observers = vec![Rc::clone(&counter), Rc::clone(&counter)];

    for observer in &observers {
        *observer.borrow_mut() += 1;
    }

    println!("计数: {}", counter.borrow());
    println!("观察者数量: {}", observers.len());
    println!("强引用计数: {}", Rc::strong_count(&counter));
}

运行时检查并非没有代价：一旦违反借用规则，程序会 panic，而不是编译失败。

rust
use std::cell::RefCell;

fn main() {
    let cell = RefCell::new(5);
    let first = cell.borrow_mut();
    let second = cell.borrow_mut(); // 运行时 panic: already mutably borrowed
    println!("{} {}", *first, *second);
}

练习 ​

练习

用 Box 定义一个表达式树，支持数字、加法与乘法三种节点，并实现 eval 计算表达式 (2 + 3) * 4。要求 eval 只借用节点，不取得所有权。

参考答案
Box 表达式树求值Rust 2021
#[derive(Debug)]
enum Expr {
    Num(f64),
    Add(Box<Expr>, Box<Expr>),
    Mul(Box<Expr>, Box<Expr>),
}

impl Expr {
    fn eval(&self) -> f64 {
        match self {
            Expr::Num(value) => *value,
            Expr::Add(left, right) => left.eval() + right.eval(),
            Expr::Mul(left, right) => left.eval() * right.eval(),
        }
    }
}

fn main() {
    // (2 + 3) * 4
    let expr = Expr::Mul(
        Box::new(Expr::Add(
            Box::new(Expr::Num(2.0)),
            Box::new(Expr::Num(3.0)),
        )),
        Box::new(Expr::Num(4.0)),
    );

    println!("{expr:?}");
    println!("= {}", expr.eval());
}

小结 ​

  • Box<T> 负责堆分配与递归类型，开销最小，所有权唯一。
  • Rc<T> 以引用计数实现单线程共享所有权，只能读。
  • RefCell<T> 把借用检查移到运行时，用 panic 换取内部可变性。
  • Rc<RefCell<T>> 是单线程共享可变状态的常见组合；跨线程需换成 Arc<Mutex<T>>。
